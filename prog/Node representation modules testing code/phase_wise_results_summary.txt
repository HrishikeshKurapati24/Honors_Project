Node Representation Modules Testing Code
Phase-Wise Results Summary

Important interpretation rules:
- Phase 0 is a smoke-testing phase only. It uses 1 epoch and 1 fold and should be read as pass/fail, not as a meaningful performance comparison.
- Phase 1 is the first scored comparison phase. The run script uses k_fold=1 and the model default epoch count from main.py (200).
- Phase 2 is the final 5-fold evaluation phase. The run script uses k_fold=5 and the same default epoch count (200).
- The logged Phase 2 baseline run failed, so the only usable baseline metrics in this folder come from baseline_results.txt.

============================================================
FINAL INTERPRETATION
============================================================

1. Phase 0 established that all planned modified node-representation experiments were runnable.

2. Phase 1 showed that:
- lighter modality combinations could match or exceed larger omics combinations,
- GraphSAGE was the strongest GNN variant in the 3-omics shortlist comparison,
- the AE cell-line module outperformed the FC cell-line module,
- the enhanced drug representation clearly outperformed the transformer-drug alternative.

3. Phase 2 showed that:
- P2_6Omics_Mutation_GIN was the best modified configuration overall,
- P2_3Omics_Mutation_GraphSAGE was the best modified configuration in AUPR,
- P2_3Omics_Chromatin_GIN was the fastest shortlisted final model.
