SOUL-CDR: Conceptual Overview of the Proposed Model

1. Motivation

Cancer Drug Response Prediction (CDRP) aims to determine whether a
specific cancer cell line will respond to a particular drug. Modern
datasets provide rich multi-omics information for cell lines and
structural information for drugs. However, several challenges arise:

-   Multi-omics data are heterogeneous and high-dimensional.
-   Drug–cell interactions occur through complex biological mechanisms.
-   Graph structures contain multiple types of relationships (drug–drug,
    cell–cell, drug–cell).
-   Local neighborhood propagation and global relational reasoning both
    play important roles.

To address these challenges, the proposed model (SOUL-CDR) combines:

1)  Multi-omics representation learning
2)  Drug molecular graph representation
3)  Heterogeneous graph learning
4)  Dual-branch relational reasoning
5)  Attention-based fusion
6)  Pairwise drug–cell prediction

The architecture is designed to learn biologically meaningful embeddings
while capturing both local and global graph relationships.

------------------------------------------------------------------------

2. High-Level Architecture

The model consists of five main stages:

1.  Drug Representation Module
2.  Cell Line Representation Module
3.  Graph Construction and Encoding
4.  Dual-Branch Graph Learning (Local + Global)
5.  Drug–Cell Interaction Prediction

Pipeline:

Drug Graph + Multi-Omics Data │ ▼ Node Representation Modules (Drug
Encoder + Cell Encoder) │ ▼ Construct Heterogeneous Graph │ ▼ Dual Graph
Learning (Local GNN + Global Graph Transformer) │ ▼ Branch Fusion │ ▼
Drug–Cell Interaction Prediction

------------------------------------------------------------------------

3. Drug Representation Module

Drugs are represented as molecular graphs where:

Nodes = atoms Edges = chemical bonds Features = atom descriptors

A Graph Neural Network (GNN) is applied to learn structural embeddings
of drugs.

Supported GNN variants include:

-   GIN (Graph Isomorphism Network)
-   GCN (Graph Convolutional Network)
-   GraphSAGE
-   GAT (Graph Attention Network)

Processing steps:

1)  Atom feature projection
2)  Multiple GNN message passing layers
3)  Nonlinear activation
4)  Global pooling (global max pooling)
5)  Fully connected projection

Output:

Drug embedding vector

Dimension:

Drug_embedding ∈ R^(hidden_dim)

------------------------------------------------------------------------

4. Cell Line Representation Module

Cell lines are represented using multiple biological data modalities:

-   Genomics
-   Epigenomics
-   Transcriptomics
-   Proteomics
-   Metabolomics
-   Pathway activity scores

Each modality is first processed using modality-specific neural
networks.

Examples:

Genomics → Fully connected network Epigenomics → Fully connected
preprocessing Transcriptomics → Deep fully connected network Proteomics
→ Lightweight FC network Metabolomics → FC network Pathway scores →
Linear projection

All modality outputs are projected into a common fusion space.

------------------------------------------------------------------------

5. Iterative Cross‑Modal Fusion

The model integrates multiple omics modalities using iterative
cross‑modal attention.

Concept:

Instead of merging all modalities simultaneously, modalities are fused
sequentially.

Example order:

Genomics → Epigenomics → Transcriptomics → Proteomics → Metabolomics →
Pathway

At each step:

fused_representation = Attention(previous_representation, new_modality)

This allows the model to:

-   capture interactions between modalities
-   progressively refine biological representations
-   avoid information dilution from simple concatenation

Output:

Cell line embedding

Dimension:

Cell_embedding ∈ R^(hidden_dim)

------------------------------------------------------------------------

6. Graph Construction

After obtaining drug and cell embeddings, a graph is constructed.

Node types:

-   Drug nodes
-   Cell nodes

Edge types:

1.  Drug–Cell edges represent drug response interactions

2.  Cell–Cell edges represent similarity between cell lines

3.  Drug–Drug edges represent structural similarity between drugs

Two graph representations are supported:

1)  Heterogeneous graph
2)  Homogeneous graph with type encoding

In the homogeneous version, node types are encoded directly into node
features.

Example:

Drug node feature: [embedding | 1 0]

Cell node feature: [embedding | 0 1]

This allows standard GNNs to distinguish node types.

------------------------------------------------------------------------

7. Dual‑Branch Graph Learning

The graph is processed using two complementary branches:

Local Graph Branch Global Graph Branch

These branches capture different aspects of the data.

------------------------------------------------------------------------

7.1 Local Graph Branch

The local branch focuses on neighborhood message passing.

Possible layers:

-   GCN
-   GraphSAGE
-   GAT
-   HeteroConv

Function:

Aggregate information from neighboring nodes.

This helps capture:

-   local topology
-   similarity propagation
-   neighborhood structure

Processing:

h = GNN(h, edge_index) h = ReLU(h) h = Dropout(h)

Output:

Local node embeddings.

------------------------------------------------------------------------

7.2 Global Graph Branch

The global branch models long‑range dependencies and relation semantics.

Two options:

1)  Heterogeneous Graph Transformer (HGT)
2)  TransformerConv

This branch uses attention mechanisms to:

-   distinguish edge types
-   model long‑range relationships
-   capture complex biological dependencies

Edge attributes encode relation types such as:

Drug–Cell Cell–Cell Drug–Drug

Processing:

h = TransformerConv(h, edge_index, edge_attr) h = ReLU(h) h = Dropout(h)

Output:

Global node embeddings.

------------------------------------------------------------------------

8. Branch Fusion

Local and global representations are combined using an attention‑based
fusion module.

Input:

h_local h_global

Fusion mechanism:

attention_weights = softmax(W * [h_local || h_global])

Final representation:

h_fused = α_local * h_local + α_global * h_global

This allows the model to adaptively balance:

-   local neighborhood information
-   global relational reasoning

Output:

Final node embeddings.

------------------------------------------------------------------------

9. Drug–Cell Interaction Prediction

To predict drug response, embeddings of drug–cell pairs are combined.

For each pair:

z_pair = [z_drug || z_cell]

This concatenated representation is passed through a prediction network.

Prediction head:

MLP: Linear → ReLU → Dropout → Linear

Output:

Logit representing probability of drug sensitivity.

------------------------------------------------------------------------

10. Model Advantages

The proposed model provides several benefits:

1)  Multi‑omics integration capturing complex biological signals
2)  Drug structure modeling using molecular graphs
3)  Heterogeneous graph reasoning capturing drug–cell relationships
4)  Dual‑branch learning combining local and global context
5)  Attention‑based fusion adapting to different relational patterns

Together, these components enable expressive representations for drug
response prediction.

------------------------------------------------------------------------

11. Summary

SOUL‑CDR is a graph‑based multi‑modal learning framework for cancer drug
response prediction that integrates:

-   molecular graph learning
-   multi‑omics fusion
-   heterogeneous graph reasoning
-   transformer‑based global context modeling

By combining these components, the model captures both biological
complexity and relational structure, enabling accurate prediction of
drug–cell responses.
