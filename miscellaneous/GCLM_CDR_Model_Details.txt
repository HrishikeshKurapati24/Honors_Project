GCLM-CDR Model Implementation Details
=====================================

Objective:
-----------
Predict cancer drug response (sensitive/resistant) using multi-omics data (genomic, epigenomic, transcriptomic) and drug molecular graphs.

Model Architecture:
-------------------
The model consists of three key modules:
1. Multi-Omics Drug Feature Representation Module
2. Graph Contrastive Learning Module
3. Cancer Drug Response Prediction Module

--------------------------------------------------
1. Multi-Omics Drug Feature Representation Module(Update the input size to match the dimensions of the available data. Finally, the model should run on my provided data.)
--------------------------------------------------

(a) Multi-Omics Input:
- Genomic mutation (MG): 34,673-dim
- Epigenomic (DNA methylation, ME): 808-dim vector
- Transcriptomic (gene expression, MN): 697-dim vector

(b) Deep Neural Network (DNN) Feature Extraction:
Each omic type is passed through a DNN to extract latent features using nonlinear activations (ReLU or PReLU).

(c) Multi-Omics Neighborhood Interaction (NI) Layer:
Captures correlations and complementarities among omics.

Equation:
    M_j = M_a ⊙ M_b, j ∈ {1,2,3}; a,b ∈ {G,E,N}, a≠b
    M_C = M_1 || M_2 || M_3

⊙ : Element-wise dot product
|| : Concatenation

(d) Drug Representation:
Input drug SMILES → molecular graphs (via DeepChem ConvMolFeaturizer)
Each atom: 75-dimensional feature vector.

Graph Definition:
    G_D = (X_D, A_D)
    X_D ∈ R^{N_D×75}, A_D ∈ R^{N_D×N_D}

Drug encoder: Graph Attention Network (GAT)
Equations:
    e_{αβ} = LeakyReLU(A^T [M h_α || M h_β])
    a_{αβ} = softmax_β(e_{αβ})
    h'_α = σ(Σ_{β∈N_α} a_{αβ} W h_β)
Global Max Pooling (GMP) is used to get the final drug embedding.

--------------------------------------------------
2. Graph Contrastive Learning Module
--------------------------------------------------

Purpose: Enhance representation by distinguishing sensitive vs. insensitive omics-drug pairs.

Graph Construction:
    G_OD = (V, E)
    V: Multi-omics nodes (O) + Drug nodes (D)
    E: Edges represent sensitivity (1) or resistance (0)

Encoder: 1-layer Graph Convolutional Network (GCN) with PReLU activation.
Equation:
    h_x^(1) = PReLU(Σ_{y∈N(x)∪{x}} (1/√(q_x q_y)) * W h_y^(0))

Attentive Readout Function:
    a_x = exp(f_a([h_x^(0) || h_x^(1)])) / Σ_{x∈V} exp(...)
    T_OD = Σ_{x∈V} a_x h_x^(1)

Contrastive Loss:
    L_pos = -1/(2|V|)[Σ log D(h_x,T) + Σ log(1 - D(ĥ_x,T))]
    L_neg = -1/(2|V|)[Σ log D(ĥ_x,Ť) + Σ log(1 - D(h_x,Ť))]
    D(h, T) = σ(h^T W T)

--------------------------------------------------
3. Cancer Drug Response Prediction Module
--------------------------------------------------

From positive patch representations, extract embeddings:
    h_O = H_OD[O,:], h_D = H_OD[D,:]

Prediction:
    P̂_OD = Sigmoid(h_O h_D^T)

Loss (binary cross-entropy):
    L_pre = -1/|Y| Σ [P_OD log P̂_OD + (1 - P_OD) log(1 - P̂_OD)]

Final Objective:
    L = (1 - λ - μ)L_pre + λL_pos + μL_neg

Hyperparameters:
    λ = 0.3, μ = 0.3

--------------------------------------------------
Dataset Details
--------------------------------------------------

Sources:
- CCLE: Multi-omics (mutation, methylation, expression)
- GDSC: Drug response (IC50 threshold → binary label)
- PubChem: Drug SMILES (used for graph construction)

Stats:
- 222 drugs, 561 cell lines
- 88,981 resistant reactions, 11,591 sensitive reactions

--------------------------------------------------
Training & Evaluation
--------------------------------------------------

Split: 9:1 (train:test)
Validation: 5-fold cross-validation (5-CV)
Metrics: AUC, AUPR

Performance:
- GDSC: AUC = 0.8534, AUPR = 0.5327
- CCLE: AUC = 0.9599, AUPR = 0.8715

--------------------------------------------------
Implementation Notes
--------------------------------------------------

- Framework: PyTorch + DeepChem
- GAT: 2–3 heads, hidden dim ≈ 128
- DNN: 3 layers per omic
- Pooling: Global Max Pooling
- Optimizer: Adam, LR = 1e-3
- Activation: PReLU
- Batch Size: 32–64
- Epochs: 100–200
- Hyperparams: λ = μ = 0.3

--------------------------------------------------
Model Flow Summary
--------------------------------------------------
Multi-omics data → DNN → NI Layer → M_C
Drug SMILES → GAT → GMP → h_D
(M_C, h_D) → Graph Contrastive Learning → h_O, h_D
→ Sigmoid(h_O · h_D^T) → Predicted sensitivity (0/1)
